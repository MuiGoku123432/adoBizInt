<objective>
Move the effort-field fix to the `internal/ado` signature so an omitted field leaves ADO
unchanged, for every caller — the CLI and the TUI alike.

Purpose: `UpdateWorkItemStateWithEffort` sends `Add` for all three effort paths on every
call today, so the daily-use TUI blind-overwrites too. This is a live bug being fixed,
not churn imposed on working code for the CLI's benefit.
Output: nullable effort parameters, updated TUI call sites with identical behaviour, and
CLI effort flags that distinguish omitted from zero.
</objective>
