Move the guarded-write body out of `cmd/adoBizInt` into a new `internal/guard` package that both the CLI and the TUI can call (GUARD-01), while keeping every CLI behaviour, stderr message, exit code, envelope and audit line identical (GUARD-06).

Design note (research SUMMARY proposed `guard.Run(ctx, op, confirm) Report`): the confirm gate becomes `Options.Confirm`, carried alongside the budget, the audit opener and the actor fields, because the CLI must keep its own `auditOpen` seam (locked tests swap it) and the TUI needs a confirm gate that compares the fresh diff to the one it showed. `Options.Actor` and `Options.UserApproved` are defined here so the TUI plans in wave 3 can set them; plan 07-03 persists them.
